🚢 Titanic Survival Prediction – Machine Learning Project
📌 Project Overview

This project focuses on predicting the survival of Titanic passengers using machine learning classification algorithms.
The goal is to analyze passenger data and build a predictive model capable of classifying survival outcomes.

🎯 Problem Statement

Given features such as age, sex, and passenger class, predict whether a passenger survived or not.

Target Variable: Survived (0 = No, 1 = Yes)
🧠 Machine Learning Pipeline

The project includes the following steps:

1. Data Preprocessing
Handling missing values
Encoding categorical variables (Sex → 0/1)
Feature scaling using StandardScaler
2. Model Training

Multiple classification models were trained and compared:

Logistic Regression
Support Vector Classifier (SVC)
K-Nearest Neighbors (KNN)
Random Forest Classifier
Gradient Boosting Classifier
Decision Tree
Gaussian Naive Bayes
